# Anjani Beesu — Portfolio

A dual-mode portfolio experience:

- **Let's get over wit it** — minimal black-and-white portfolio.
- **Creative version** — dark, expressive layout with lime accents and animated orbit.
- Intro loader — thin white progress bar on a black screen.

## Customize
Edit `index.html` and replace:
- About copy
- Project cards and descriptions
- Skills/toolkit rows
- Email address (`your-email@example.com`)
- Project links, social links, and dates

## Deploy on GitHub Pages
1. Open repository **Settings → Pages**.
2. Under Build and deployment, select **Deploy from a branch**.
3. Choose `main` and `/(root)`, then Save.
4. Wait for the deployment and open the Pages URL.

Everything is implemented in one HTML file with inline CSS and JavaScript.
